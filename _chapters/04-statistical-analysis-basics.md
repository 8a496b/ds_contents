# 통계분석 기초

---

## 1. 통계분석의 정의와 목적

**통계분석(Statistical Analysis)**이란 데이터를 수집하고, 정리·요약하여 의미 있는 정보를 추출하거나, 그 데이터를 바탕으로 불확실한 미래 또는 더 큰 집단에 대한 결론을 도출하는 과학적 방법론입니다.

### 목적

| 목적 | 설명 |
|------|------|
| **요약 및 기술** | 복잡한 데이터를 이해하기 쉬운 수치나 그래프로 요약 |
| **패턴 발견** | 데이터 내의 규칙, 경향, 관계를 탐색 |
| **추론 및 예측** | 표본 데이터를 통해 전체 모집단의 특성을 추정 |
| **의사결정 지원** | 불확실한 상황에서 과학적 근거를 제공 |

---

## 2. 통계분석의 분류

통계학은 크게 **기술통계학**과 **추론통계학**으로 나뉩니다.

### 2.1 기술통계학 (Descriptive Statistics)

> 수집된 데이터 자체를 **요약하고 묘사**하는 것이 목적입니다. 데이터 너머의 무언가를 추론하지 않습니다.

**주요 방법:**
- 평균, 중앙값, 최빈값 (대표값)
- 분산, 표준편차 (퍼짐 정도)
- 히스토그램, 상자그림 (시각화)

**예제:**

우리 반 학생 30명의 수학 점수를 수집했습니다.

```
점수: [72, 85, 91, 68, 74, 88, 95, 77, 83, 69, ...]
```

- **평균 점수**: 80.2점
- **최고 점수**: 98점 / **최저 점수**: 55점
- **표준편차**: 10.3점

→ 이 결과는 "이 반 학생들"에 대한 사실을 있는 그대로 요약한 것입니다.

---

### 2.2 추론통계학 (Inferential Statistics)

> **표본(sample)**으로부터 **모집단(population)** 전체의 특성을 추정하고, 가설을 검정하는 것이 목적입니다.

**주요 방법:**
- 신뢰구간 추정
- 가설 검정 (t-검정, 카이제곱 검정 등)
- 회귀분석

**예제:**

전국 고등학생의 평균 수면 시간을 알고 싶습니다. 전수조사는 불가능하므로 500명을 무작위로 표본추출하여 조사했습니다.

```
표본 500명의 평균 수면 시간: 6.8시간
표준오차: 0.1시간
```

→ **추론**: "전국 고등학생의 평균 수면 시간은 95% 신뢰수준에서 6.6 ~ 7.0시간일 것이다."

→ 표본 결과를 바탕으로 **알 수 없는 모집단**에 대해 결론을 내리는 것이 추론통계학입니다.

---

## 3. 관련 용어 설명

### 모집단 (Population)

연구 대상이 되는 **전체 집합**입니다.

> 예: "대한민국 성인 남성 전체의 평균 키"를 연구한다면, **대한민국 성인 남성 전체**가 모집단입니다.

---

### 표본 (Sample)

모집단에서 실제로 **추출하여 관측한 일부**입니다.

> 예: 위 연구에서 전국에서 무작위로 뽑은 **1,000명의 성인 남성**이 표본입니다.

---

### 표본추출 (Sampling)

모집단에서 표본을 **선택하는 과정**입니다. 표본이 모집단을 잘 대표해야 분석 결과를 신뢰할 수 있습니다.

| 방법 | 설명 |
|------|------|
| 단순 무작위 추출 | 모든 개체가 동일한 확률로 선택됨 |
| 층화 추출 | 집단을 층으로 나눈 후 각 층에서 추출 |
| 군집 추출 | 집단을 군집으로 나누고 군집 단위로 추출 |

---

### 모수 (Parameter)

**모집단**의 특성을 나타내는 수치입니다. 일반적으로 직접 알기 어렵고, 추론의 대상이 됩니다.

> 예: 대한민국 성인 남성 **전체**의 평균 키 → **모수** (실제로 측정 불가)

---

### 통계량 (Statistic)

**표본**으로부터 계산된 수치입니다. 모수를 추정하기 위해 사용됩니다.

> 예: 표본 1,000명의 평균 키 → **통계량** (직접 계산 가능)

---

## 4. 주요 개념 간의 관계

```
┌─────────────────────────────────────────────────┐
│                   모집단 (Population)             │
│                                                  │
│   특성값 = 모수 (Parameter)                       │
│   예) 모평균 μ, 모분산 σ²                          │
│                                                  │
│          │ 표본추출 (Sampling)                    │
│          ▼                                       │
│  ┌───────────────────────┐                       │
│  │    표본 (Sample)       │                       │
│  │                        │                      │
│  │  특성값 = 통계량        │                      │
│  │  예) 표본평균 x̄, s²    │                      │
│  └───────────────────────┘                       │
│          │ 추론 (Inference)                       │
│          └──────────────────────────────────►   │
│                      모수 추정 / 가설 검정          │
└─────────────────────────────────────────────────┘
```

- **모집단** → 표본추출 → **표본**
- **표본**에서 **통계량** 계산
- **통계량**으로 **모수** 추론

---

## 5. 모수와 통계량의 주요 기호

| 특성 | 모수 (모집단) | 통계량 (표본) |
|------|:---:|:---:|
| **평균** | $\mu$ (뮤) | $\bar{x}$ (엑스바) |
| **분산** | $\sigma^2$ (시그마 제곱) | $s^2$ |
| **표준편차** | $\sigma$ (시그마) | $s$ |
| **비율** | $p$ | $\hat{p}$ (피햇) |
| **크기** | $N$ | $n$ |

> **기억법**: 모수는 **그리스 문자**, 통계량은 **로마자(영어 알파벳)**로 표기하는 것이 관례입니다.

## 6. 데이터셋의 구조

### 행(Row)과 열(Column)로 이루어진 표

실제 데이터는 대부분 **표(table)** 형태로 표현됩니다.

- **행(Row)**: 하나의 관측값 → **데이터 포인트(data point)** 또는 **관측치(observation)**
- **열(Column)**: 각 관측치가 가지는 속성 → **변수(variable)** 또는 **특성(feature)**

---

### 변수의 종류: 독립변수 vs 종속변수

| 구분 | 다른 이름 | 설명 |
|------|-----------|------|
| **독립변수** | 설명변수, 특성(feature), 입력변수, $X$ | 결과에 영향을 주는 변수 |
| **종속변수** | 결과변수, 타겟(target), 출력변수, $y$ | 예측하거나 설명하고자 하는 변수 |

---

## 7. 데이터 테이블 예제

다음은 학생들의 시험 성적 데이터셋입니다.

| 학번 | 공부시간(h) | 수면시간(h) | 과외여부 | 점수 |
|:----:|:----------:|:----------:|:------:|:----:|
| S001 | 5 | 7 | O | 88 |
| S002 | 2 | 8 | X | 65 |
| S003 | 7 | 6 | O | 95 |
| S004 | 3 | 9 | X | 70 |
| S005 | 6 | 7 | O | 91 |

```
┌──────────────────────────────────────────────────────────┐
│                   데이터셋 (Dataset)                       │
│                                                           │
│       변수1      변수2      변수3      변수4    [종속변수]  │
│  ┌────────────────────────────────────────────────────┐  │
│  │  공부시간  │ 수면시간  │ 과외여부 │   점수          │  │
│  ├────────────────────────────────────────────────────┤  │
│  │    5      │    7     │    O    │    88    ◄──────┐ │  │
│  │    2      │    8     │    X    │    65           │ │  │
│  │    7      │    6     │    O    │    95    데이터  │ │  │
│  │    3      │    9     │    X    │    70    포인트  │ │  │
│  │    6      │    7     │    O    │    91    (행)   │ │  │
│  └────────────────────────────────────────────────────┘  │
│       ▲                              ▲                    │
│  독립변수(X)                      종속변수(y)              │
│  (설명변수, feature)              (결과변수, target)        │
└──────────────────────────────────────────────────────────┘
```

- **데이터 포인트**: 각 행 (예: S003 학생 한 명의 관측값)
- **변수(Variable)**: 각 열 (예: 공부시간, 점수 등)

## 8. 변수의 종류

변수는 크게 **수치형**과 **범주형**으로 나뉩니다.

```
변수 (Variable)
├── 수치형 (Numerical)
│   ├── 연속형 (Continuous)   예) 키, 몸무게, 온도
│   └── 이산형 (Discrete)     예) 자녀 수, 클릭 수
└── 범주형 (Categorical)
    ├── 명목형 (Nominal)      예) 성별, 혈액형
    ├── 순서형 (Ordinal)      예) 학점(A/B/C), 만족도
    ├── 구간형 (Interval)     예) 섭씨 온도, IQ
    └── 비율형 (Ratio)        예) 키, 몸무게, 소득
```

---

### 8.1 수치형 변수 (Numerical Variable)

숫자로 표현되며 **사칙연산이 의미**를 가집니다.

#### 연속형 (Continuous)
- 측정값이 **연속적인 실수** 범위를 가집니다.
- **예제**: 키(175.3cm), 몸무게(68.2kg), 기온(23.7°C)
- "두 값 사이에 항상 다른 값이 존재할 수 있다"

#### 이산형 (Discrete)
- 셀 수 있는 **정수값**을 가집니다.
- **예제**: 가족 수(3명), 하루 이메일 수(47개), 주사위 눈(1~6)
- "딱 떨어지는 값만 가능하다"

---

### 8.2 범주형 변수 (Categorical Variable)

**그룹이나 범주**를 나타냅니다. 숫자로 표현되더라도 사칙연산이 의미 없을 수 있습니다.

#### 명목형 (Nominal) — "이름만 다를 뿐, 순서 없음"
- 범주 간에 **순서나 크기 관계가 없습니다.**
- **예제**: 혈액형(A/B/O/AB), 성별(남/여), 거주 지역(서울/부산/대구)
- "A형이 B형보다 크다" → 의미 없음

#### 순서형 (Ordinal) — "순서는 있지만, 간격은 불명확"
- 범주 간에 **순서는 있지만**, 간격이 동일하지 않습니다.
- **예제**: 학점(A > B > C > D), 설문 만족도(매우만족 > 만족 > 보통 > 불만족), 군 계급
- "'매우만족'이 '만족'보다 정확히 2배 좋다" → 말할 수 없음

#### 구간형 (Interval) — "순서도 있고 간격도 동일, 그러나 절대 0이 없음"
- 값 간의 **간격이 동일**하지만 **절대적인 0이 없습니다.**
- **예제**: 섭씨 온도(0°C는 온도 없음이 아님), IQ 점수, 연도(서기)
- "20°C는 10°C보다 10도 높다" → 말할 수 있음
- "20°C가 10°C보다 2배 덥다" → 말할 수 **없음**

#### 비율형 (Ratio) — "절대 0이 존재하며 모든 계산 가능"
- **절대적인 0**이 존재하여 비율 비교가 가능합니다.
- **예제**: 키(0cm = 없음), 몸무게, 소득, 거리, 시간
- "200cm는 100cm의 2배다" → 말할 수 있음

---

### 변수 종류 요약 비교

| 척도 | 순서 | 동일 간격 | 절대 0 | 예제 |
|------|:----:|:--------:|:-----:|------|
| **명목형** | ✗ | ✗ | ✗ | 혈액형, 성별 |
| **순서형** | ✓ | ✗ | ✗ | 학점, 만족도 |
| **구간형** | ✓ | ✓ | ✗ | 온도(°C), IQ |
| **비율형** | ✓ | ✓ | ✓ | 키, 몸무게, 소득 |

> **팁**: 위로 갈수록 정보가 적고, 아래로 갈수록 더 풍부한 통계 분석이 가능합니다.  
> 비율형 > 구간형 > 순서형 > 명목형 순으로 분석의 자유도가 높습니다.

## 정리

```
통계분석
├── 기술통계학: 데이터 자체를 요약·묘사
└── 추론통계학: 표본으로 모집단에 대한 결론 도출

핵심 개념
├── 모집단 → 모수 (μ, σ², p)
└── 표본   → 통계량 (x̄, s², p̂)

데이터셋
├── 행 = 데이터 포인트 (관측치)
├── 열 = 변수
├── 독립변수 X (설명변수, feature)
└── 종속변수 y (결과변수, target)

변수 종류
├── 수치형: 연속형, 이산형
└── 범주형: 명목형, 순서형, 구간형, 비율형
```
